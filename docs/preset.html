Load the settings for a preset by selecting it from the dropdown and clicking the load button.

Save the current settings to a preset by filling in the preset name and clicking save. Master Speed and Depth values are not saved to presets, but all other values and modifiers are. This is a safety feature.

Renaming is possible through a three step process:
  • Load the old pattern above.
  • Type the new name in the box and save it with those settings.
  • Reselect the old pattern by name and click delete.

Click the get button to get a sharing code you can copy to others. Write a sharing code and click set to try it out. SHARED CODES DO SET YOUR DEPTH VALUES, so setting one will pause the machine.

Factory reset will delete all presets and load the default library of presets.

Requirements: Chrome, Edge, or Opera on desktop or Android.
